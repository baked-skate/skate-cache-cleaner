# baked. cache clearing tool

Clears skate.'s cache for you, on ReSkate or plain skate. Use it when the game crashes, looks wrong or stutters.

## How to use it

1. Click the big button above. It downloads `baked-cache-clearing-tool.zip`.
2. Close skate.
3. Open your Downloads folder and double-click the zip to open it.
4. Double-click `ClearSkateCache.bat` inside it.
5. Press **Y** for yes or **N** for no. It shows you the folder before it deletes anything.

The game rebuilds the cache the next time you play, so your first load may be a little slower.

## Windows asks if you want to run it?

That's normal for a small tool like this that nobody paid to sign.

- **"Do you want to run this file?":** click **Run**.
- **"Windows protected your PC":** click **More info**, then **Run anyway**.
- **Your browser warns about the download:** choose **Keep**.

## Good to know

The ReSkate launcher already clears this cache by itself when you add or remove mods. You only need this tool when something's wrong and your mods haven't changed.

It only empties these two folders:

- `%LOCALAPPDATA%\ReSkate\Game\Skate\cache`
- `%LOCALAPPDATA%\Skate\cache`

Your saves, settings and mods aren't touched.
